# Phishing Awareness Training - CodeAlpha Internship

## 📌 Project Overview
This project is a presentation focused on phishing attacks, how they work, and how users can protect themselves from such threats.

## 📚 Contents Covered
- What is Phishing
- Types of Phishing (Email, Spear, Smishing)
- Real-world phishing examples
- Fake website detection
- Social engineering tactics
- Prevention techniques
- Interactive quizzes

## 🎯 Objective
To educate users about phishing attacks and improve awareness to prevent cyber threats.

## 📊 File Included
- CodeAlpha_PhishingAwareness.pdf

## 🎯 Learning Outcome
- Ability to identify phishing attempts
- Awareness of social engineering techniques
- Understanding of online safety practices
